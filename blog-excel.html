10 Excel Formulas Every Freelancer Should Know

The handful of formulas that save hours of manual work every single week.

Excel and Google Sheets remain some of the most searched productivity tools in the world — and knowing a handful of formulas well can save you hours of manual work every single week. You don't need to be a spreadsheet expert. You just need to know the right ten.

1. SUM / SUMIFS

The most basic and most-used formula in spreadsheets — adding up a range of values. SUMIFS extends this by letting you add values only when they meet one or more conditions, which is essential for anything involving categories or filtered totals.

2. IF

Returns different results depending on whether a condition is true or false. This is the foundation of almost all conditional logic in spreadsheets, from simple pass/fail checks to complex nested decision trees.

3. VLOOKUP / XLOOKUP

Pulls matching data from another table based on a shared reference — extremely useful for combining data from multiple sheets. XLOOKUP is the newer, more flexible version and is worth learning first if you're starting fresh.

4. COUNTIF

Counts how many cells in a range meet a specific condition. Useful for quick summaries — how many orders came in this week, how many entries are marked "complete," and similar counting tasks.

5. CONCAT / TEXTJOIN

Combines text from multiple cells into one — useful for merging first and last names, building formatted labels, or assembling messages from separate data fields.

6. TODAY()

Automatically inserts today's date, which updates every time the sheet is opened. Useful for tracking deadlines, ages, or time-since-date calculations without manually updating dates.

7. IFERROR

Shows a clean, custom message instead of a default error code when a formula fails — makes spreadsheets much more presentable when sharing with clients or teammates.

8. Conditional Formatting

Not a formula exactly, but essential — automatically highlights cells based on rules you set, making it easy to visually spot overdue items, low stock, or outliers without reading every row manually.

Where to Start

You don't need to memorize all of these at once. Start with SUM, IF, and VLOOKUP — together they cover the majority of everyday spreadsheet tasks. Add the rest as you run into situations that need them.

Final Thoughts

Most people only ever use a fraction of what spreadsheets are capable of. Learning even five or six of these formulas well can turn hours of manual data work into a few minutes of formula-driven automation.
